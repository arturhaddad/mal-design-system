# React Native

`Button` and `TransactionCard`, built a second time for a React Native app. The stories in this section run that code in your browser, through react-native-web.

## What the two versions share

- **The tokens.** The native components read the theme generated from the same CSS as the web utilities.
- **The contract.** Each component declares its variants and props once. The web and the native version both extend that type.
- **The words.** Both print the amount and the date that one function formats.

They do not share the implementation. The web version is HTML with static CSS. The native version is `Pressable`, `View` and `Text`.

## How to look around

- **Theme** in the toolbar switches the native theme too. In an app, the device setting does that.
- **Beside the web** is a story on each component, with the two versions one above the other.
- **Interactions** replays a press on the native component, and on the Button a keyboard press too.

## What this preview does not show

The components have not run on a phone or in a simulator, and this repository has no app. A browser shows their layout, colours and behaviour. It does not show a phone's fonts, keyboard, screen reader or right-to-left layout.

The native versions are smaller than the web ones. They take no custom icon, and the card has no link form. The direction arrow is drawn from two plain views, because the web icons are SVG and React Native needs a library to draw them. And there are no Arabic stories here yet.
